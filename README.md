# hanan-portfolio
Coding Portfolio
Live link: https://hanan7x.github.io/hanan-portfolio/
## What it is

A single-page personal portfolio site. It introduces me, gives a short "About Me," lists a few academic and extracurricular achievements, and provides a way to get in touch through email and social links.

## How I built it

The whole site is one self-contained index.html file — semantic HTML5 (header, nav, main, section, footer) with all styling written in a single <style> block, so there are no separate CSS or build files to manage. It uses CSS custom properties for a consistent color palette, Google Fonts (Poppins for headings, Inter for body text) for typography, and a subtle fade-in animation on each section that respects prefers-reduced-motion for accessibility. The layout is responsive with fluid type sizing and a mobile breakpoint.

## AI-assisted decision

I used Claude to help me choose and refine the color palette and font pairing (Poppins + Inter) so the page reads as clean and professional rather than using whatever fonts and colors I might have defaulted to on my own.
